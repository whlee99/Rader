2. IO Map 

2.1 TFmini Plus
   - 보드: TFmini Plus (Benewake)
   - 인터페이스: UART2 (115200 baud, 8N1)
   - 프레임: 9바이트, 100Hz
     [0x59][0x59][DistL][DistH][StrL][StrH][TempL][TempH][Checksum]
   - GPIO 배선:
     ESP32 GPIO16 (UART2 RX) ←→ TFmini Plus TX
     ESP32 GPIO17 (UART2 TX) ←→ TFmini Plus RX
   - 전원: 5V / GND
   - 감지 방식: 부팅 시 UART2 에서 500ms 동안 유효 프레임 수신 시도.
     수신 성공 시 TFmini 모드, 실패 시 VL53L5CX 모드로 자동 전환.

2.2 VL53L5CX
      message : 
      {"m":"cx","d":[11,16,17,15,479,474,725,788,12,16,17,16,398,446,460,845,14,13,17,15,14,414,458,909,13,15,12,17,13,15,289,467,9,12,15,20,20,14,116,15,14,14,15,16,16,17,335,378,12,14,16,16,17,21,19,740,14,17,16,16,17,18,18,692]}
      

   - 보드: Pololu VL53L5CX Time-of-Flight Sensor Carrier (irs18a PCB)
     제품번호: Pololu #3417
     (동일 PCB 로 VL53L7CX #3418 도 존재. 광학 개구부 형상으로 구분)
   - 인터페이스: I2C
   - I2C 주소: 0x29 (7-bit), 파워업 기본값
   - I2C 클럭: 50kHz (케이블 길이 ~30cm 고려, 레벨시프터 안정성)

   GPIO 배선:
     ESP32 GPIO5  ←→ 보드 SDA  (I2C Data)
     ESP32 GPIO4  ←→ 보드 SCL  (I2C Clock)
     ESP32 GPIO34 ←→ 보드 INT  (인터럽트, 현재 미사용 / 폴링 방식)
     보드 RST          N.C.    (보드 내부 GND 풀다운, 연결 불필요)
                               ※ RST 는 active-HIGH: HIGH 인가 시 I2C 리셋
                                  GND 고정(기본) = 정상 동작
     보드 LPN          3.3V 고정 (active-LOW disable, HIGH=정상동작)
                               ※ 보드 내부 VDD 풀업 있음. CPU 연결 불필요.

   전원 배선:
     ESP32 5V  (VIN) ←→ 보드 VIN  (레귤레이터 + 레벨시프터 전원)
     ESP32 3.3V      ←→ 보드 VDD  (I2C 레벨시프터 LOW측 기준전압)
                               ※ VDD 미연결 시 I2C 레벨시프터 동작 불가
                                  → NACK (err=2) 발생
     ESP32 GND       ←→ 보드 GND

   I2C 풀업:
     SDA, SCL 각각 2.2kΩ → 3.3V (외부 풀업, 30cm 배선 대응)

   ESP32 는 MQTT Publisher 이며, TOPIC 는 "RDR" 이다.

   3.1 센서 데이터 UDP 송출 (200ms 주기, 192.168.0.20:8096)

   TFmini Plus 포맷:
     {"dist":<cm>,"str":<strength>,"temp":<°C>}

   VL53L5CX 포맷:
     {"m":"cx","d":[d0,d1,...,d63]}
     (8x8=64 zones, 단위 mm, 좌상단→우하단 순서)

   3.2 Debug UDP 송출 (UDP 8096)

   디버그 목적으로 센서 데이터와 시스템 상태를 UDP 8096 포트로 추가 송출한다.

   3.2.1 송출 대상
     - Unicast  : 192.168.0.20:8096
     - Multicast: 239.255.3.4:8096 (동시 송출)

   3.2.2 송출 주기
     - 센서 데이터 : 200ms 주기 (3.1 과 동일 패킷 재사용)
     - 시스템 상태 : 1000ms 주기

   3.2.3 Debug 메시지 포맷

   센서 데이터 (기존 포맷 그대로):
     TFmini Plus : {"dist":<cm>,"str":<strength>,"temp":<°C>}
     VL53L5CX   : {"m":"cx","d":[d0,d1,...,d63]}

   시스템 상태:
     {"type":"dbg","uptime":<ms>,"sensor":"<tfmini|vl53>",
      "wifi":<rssi>,"ip":"<ip>","free_heap":<bytes>,"err":<code>}

     필드 설명:
       uptime    : 부팅 후 경과 ms (millis())
       sensor    : 현재 활성 센서 ("tfmini" 또는 "vl53")
       wifi      : WiFi RSSI (dBm), 미연결 시 0
       ip        : 현재 IP 문자열
       free_heap : ESP.getFreeHeap() 반환값 (bytes)
       err       : 0=정상, 1=센서오류, 2=WiFi끊김, 3=MQTT오류

   3.3 미결정 사항
   1. GPIO 핀 상태에 따라, TFmini Plus 또는 VL53L5CX 의 센서 값을 Publish 한다.
 
   2. GPIO 핀 으로 정상 상태 또는 ERROR 상태를 표시한다. 


4. LAN8720 연결

4.1 핀 매핑 (RMII 인터페이스)

   ESP32 DevKitC-V4    기능          LAN8720
   ──────────────────────────────────────────────────────
   IO19               TXD0          TXD0
   IO22               TXD1          TXD1
   IO21               TX_EN         TX_EN
   IO25               RXD0          RXD0/MODE0      ← 10K Pull-up
   IO26               RXD1          RXD1/MODE1      ← 10K Pull-up
   IO27               CRS_DV        CRS_DV/MODE2    ← 10K Pull-up
   IO18               MDIO          MDIO            ← 10K Pull-up
   IO23               MDC           MDC
   IO17               CLK (50MHz 출력)  XTAL1/CLKIN
   IO32               nRST            nRST (active-LOW)

   CLK 공급 방식 : ESP32 GPIO17 출력 (ETH_CLOCK_GPIO17_OUT)
                  → GPIO17 을 LAN8720 에 공급하므로 UART2 TX 미사용
                  → config.h: TFMINI_TX_PIN = -1

4.2 하드웨어 Pull-up / 부트스트랩

   RXD0 / RXD1 / CRS_DV 는 리셋 해제 시 MODE[2:0] 로 샘플링됨.
   세 핀 모두 10K Pull-up → MODE[2:0] = 111
   → LAN8720 All-Capable (10/100, Half/Full) + Auto-negotiation ON

   MDIO 10K Pull-up → 버스 idle 시 HIGH 유지 (IEEE 802.3 규격)

4.3 PHY 주소 (PHYAD0 / RXER 핀)

   PHYAD0 = GND  → PHY 주소 0  (기본값, config.h ETH_PHY_ADDR = 0)
   PHYAD0 = VCC  → PHY 주소 1
   ※ Reg18=0xC1C1 (PHYAD=1) 로 읽히지만 ETH.begin(addr=0) 으로 정상 동작 확인.
      MDIO bit-bang 과 EMAC 내부 MDIO 경로가 다르게 동작하는 것으로 추정.

4.4 nRST 처리 (GPIO32)

   GPIO32 → LAN8720 nRST (active-LOW)
   ETH.begin() 두 번째 인수(power 핀)에 GPIO32 를 전달하면
   Arduino-ESP32 ETH 라이브러리가 아래 순서를 자동으로 처리:

     1) GPIO32 LOW  → LAN8720 리셋 유지
     2) GPIO17 RMII 클럭(50MHz) 출력 시작
     3) GPIO32 HIGH → 클럭 안정 후 리셋 해제 + MODE 핀 샘플링
     4) MDIO 를 통한 PHY 초기화

   ※ nRST 를 RC 회로로만 처리하면 CLK 공급 전에 리셋이 해제될 수 있음
      → PHY 내부 state machine 초기화 불완전 → 링크 불안정 위험
      GPIO 제어 방식이 필수.
   ※ nRST 에 4.7µF 이상 캐패시터 금지: ETH.begin() 내부 LOW 펄스(~200µs)로
      충분히 방전 불가 → 리셋 미인식. 10kΩ 풀업만 사용.

4.5 GPIO17 충돌 해소

   기존 TFMINI_TX_PIN = 17 (UART2 TX) 이었으나,
   TFMini Plus 는 ESP32 수신 전용(단방향)이므로 TX 핀이 실제 불필요.
   Serial2.begin(..., RX_PIN, -1) 으로 TX 미할당 → GPIO17 해방.
   변경 후: TFMINI_TX_PIN = -1

4.6 센터탭 바이어스 저항 (필수)

   RJ45 내장 트랜스포머(RD1-125BAG1A 등)의 센터탭 핀에
   49.9Ω (또는 47~51Ω 1%) 저항 → 3.3V 연결 필수.

   대상 핀:
     TX 트랜스포머 센터탭 → 49.9Ω → 3.3V
     RX 트랜스포머 센터탭 → 49.9Ω → 3.3V

   미장착 시 공통 모드 전압 불안정 → TX 신호 왜형 → 스위치 미인식
   → DHCP 패킷 전송 실패 → 링크 불가.
   ※ 실측: 저항 미장착 시 링크가 10Mbps Half 로만 협상되고 DHCP 실패.
             저항 장착 후 100Mbps Full-Duplex 링크 및 DHCP 정상 동작 확인.

4.7 test lan8720 (Minishell 명령)

   실행 절차:
   1) ETH.begin (ETH_PHY_LAN8720, ETH_CLOCK_GPIO17_OUT)
      - GPIO32 로 nRST 시퀀스 자동 처리
   2) MDIO verify: PHY ID 확인 + 주요 레지스터 덤프
      - Addr 0: ID1=0x000F  ID2=0x81E3 → LAN8720 family OK (SMSC8720A)
   3) 링크 업 대기 (최대 5초)
      - 100Mbps Full-Duplex 확인
   4) DHCP IP 대기 (최대 8초)
      - PoE L2 스위치 사용 시 STP 수렴(~45초) 주의 → PortFast 활성화 권장
   5) GW (env.gw) 로 ICMP Ping x3
      - 실측: success=3/3, avg=0.6ms

5.5 센서 자동 선택 로직 (부팅 시)

  부팅
   │
   ├─ UART2 (GPIO16) 에서 TFMini 프레임 감지 (500ms 대기)
   │       │
   │  감지 성공 ──→ TFMini Plus 모드
   │               GPIO16 = UART2 RX  (TFMini TX 수신)
   │               GPIO17 = LAN8720 CLK (UART2 TX 미사용)
   │
   └─  감지 실패 ──→ VL53L5CX 모드
                    Serial2.end()
                    GPIO16 = I2C_RST 출력으로 재사용
                    I2C: GPIO5(SDA) / GPIO4(SCL)
